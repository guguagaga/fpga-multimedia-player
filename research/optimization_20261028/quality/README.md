# Codec10兼容颜色优化实验

输入是原Codec9文件与stdin的1280×720 RGB565LE原始参考帧；当前工具仍是研究原型，使用方式沿用已有离线链路。输出C9需另用repack_codec10转成C10并验证。本目录不含原视频或样片媒体。

`refine_quantized.cpp input_c9 output_c9 weight discrete_flag`：从8轮连续Jacobi拟合开始，量化代表色，再以正反顺序进行6轮整数坐标下降；每个颜色通道取条件二次目标的最近整数，目标为像素SSE加权块边残差梯度SSE。冻结候选为weight=0.9、discrete_flag=1。传0时为连续拟合对照。保持全部块模式、掩码和RAW像素，因此不增加硬件模式或C9帧大小，C10文件大小仍需重新测量。

`refine_source_adaptive.cpp input_c9 output_c9 weight edge_scale`：按原图跨块色差衰减块边权重，实验未同时改善当前方案的像素与块边指标，未采用。两种工具的第五个参数意义不同。

先在18/67/154/276/401秒各3帧共15帧调参，再冻结discrete09，在35/110/210/335秒各3帧共12帧复核。后者与调参片段时间位置不同，但仍来自同一影片，不证明其他影片上的收益。`discrete_fine/results.json`中的edge_scale字段是实验脚本沿用名称，在离散实验中表示discrete_flag，而非梯度尺度。

未参与调参样本：现方案PSNR34.297857dB、grid8=7.073005；discrete09为34.312615dB、grid8=7.052686。即+0.014757dB、grid8误差下降约0.287%。属于很小的代理指标改进，不能称明显观感提升。相对于未优化Q165，仍有像素误差与块边平滑的取舍。全部27帧规范化与模式/掩码/RAW不变检查通过。

尚未重新编码整片、重测实际SD吞吐或上板；未替换活动视频。实验源码保持原有输入假设，不作为通用不可信文件解析库。
