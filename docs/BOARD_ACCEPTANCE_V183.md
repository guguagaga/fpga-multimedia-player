## 文件准备

根目录最多四组 `M1*.VID` / `V1*.VAU` 至 `M4*.VID` / `V4*.VAU`。
每个编号只保留一个视频和一个配套音轨。把旧副本改为 `.BAK` 才能排除扫描。
不要同时复制 `media_demo` 的第一组与原卡的第一组。

四组原创短样本适合快速检查顺序：红/440Hz、绿/660Hz、蓝/880Hz、黄/1100Hz，各2秒。
真实长片验收可用原卡第一组加新素材第二组；新素材文件另行提供，不包含在 GitHub 公布的演示包里。

## 检查项目

| 项目 | 操作 | 期望 | 实测记录 |
|---|---|---|---|
| 上电基本功能 | 复位后检查图片、音乐和按键 | 保持原版基本功能 | 待测 |
| 自动轮播 | 四组短样本连续循环10轮 | 1→2→3→4→1，颜色与音调始终匹配 | 待测 |
| 手动切换 | 视频模式按扩展KEY1/KEY2，交替20次 | 下一部/上一部，首尾循环，新片从头开始 | 待测 |
| 暂停后切换 | KEY0暂停，再KEY1或KEY2 | 新片正常从头播放，不保持旧暂停状态 | 待测 |
| 切换期间重复按键 | 预读期间再次按前后切换 | 忽略忙期间新增切换，不积累无穷队列 | 待测 |
| 退出恢复音乐 | 音乐播放中进入视频，换片后KEY3退出 | 原歌曲从头播放，按播放键仍可正常控制 | 待测 |
| 预读时退出 | 按下一部后立刻KEY3退出，重复5次 | 正常退出，读卡不挂起，音乐可恢复 | 待测 |
| 单片回归 | 卡上只保留一组可识别视频/音轨 | 前后切换和自动结束均重播该片 | 待测 |
| 长片同步 | 用原片与新素材自动播放两轮 | 全片无持续拖音、无中途音频回头，尾部正常切换 | 待测 |
| 退出后的图片 | 视频退出后切换高/低分辨率图片 | 图片显示、缩放适配、预读继续正常 | 待测 |

自动切换需要最后一帧和配套PCM都播放完。切换有停止旧读卡、排空音轨和预读新片的等待，不要求无缝接播。
单组文件不能验证不同文件间的切换；纯色低码率样本不能替代真实长片的吞吐验收。

出现问题请记录：当前编号、自动还是手动、发生时刻、按键顺序、数码管显示和可重复步骤。
损坏的视频/音频文件不在本版“自动跳过所有故障文件”的承诺范围内；缺少配对文件的编号会跳过。
