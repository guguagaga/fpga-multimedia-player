# v186：720P30 HDMI 修复与上板确认

原 v185 上电立即 HDMI 无信号，同接线旧 v183 能显示。补查发现 video_clk 和 hdmi_5x_clk 来自同一 PLL，却被原 SDC 同时按互斥/异步时钟排除。恢复同步检查后，失败 v185 的相关路径 setup 为 -0.433ns；能显示的 R3 诊断版为 +0.709ns，实际交付 v183 为 +0.147ns。这支持修复方向，不能仅凭相关性宣称单一根因已穷尽。

v186 删除互斥分组，把像素/串行时钟放入同一个跨域分组；其余可执行 SDC 约束保持不变。约束修复后剩余图片缩放 fit_h -> state 路径最差 -0.069ns。增加 V_CHECK 状态寄存纵向比较结果，再在 V_STEP 更新余量和状态，保持采样位置与黑边计算不变。

最终独立 routed STA：setup +0.265ns，hold +0.030ns，零违例，覆盖率96.31%。像素→串行路径 setup +0.889ns、hold +0.213ns。工具的同进程 QoR 曾给出过于乐观的数值，因此交付使用新进程重开数据库的报告。
