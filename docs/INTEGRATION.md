# v19 快速读图整合

日期：2026-10-26。基线为 v18 音画同步/图片横线修复；快速读图来自同学 2026-10-26 交付，按功能手工移植，避免覆盖新版媒体通路。

3. `sd_card_bmp.v`：将load_busy声明移到首次使用之前，兼容ModelSim编译，不改变预取/800直通行为。
