# v188 提前预读实验最终结论

## 功能收益

在固定加速仿真模型中，音频FIFO达到高水位时提前启动下一张图片预读，第一次切换等待由5,546,313降至4,000,053周期，第二次由11,059,797降至8,000,106周期，减少约27.9%。QOI三帧和BMP两帧各921,600像素通过；音频FIFO模型最低约6096字节；12次长图片事务模型最低3165字节；控制、视频锁、失败预读恢复及40次按键测试通过。

## 时序结论

直接使用14位`fifo_usedw >= 6144`的准入比较，独立生产SDC setup -1.343ns/17端点。改成复用已有`fifo_lvl==3`单比特后，seed24、seed12、seed26均为setup -0.030ns/1端点，hold +0.032ns/0端点。9时钟、HDMI同步路径和覆盖类别均通过，但真实setup仍未过。

因此v188不生成验收包、不上板、不覆盖R3。实验bit保留在D盘作追溯，不要烧录。预读收益成立，时序实现失败；下一次必须把准入移出当前SD时钟关键路径，改成独立时隙/事件调度或在现有仲裁器内部复用已有事务状态，不能继续只换seed。

## 自动切图计时基准修正（待重新签核）

检查通路后发现，原计时器在到点发出切图请求时立即把 `sec_cnt` 清零；如果下一张仍在读卡、写帧或等待淡出握手，下一次周期会从零重新开始，实际间隔就会随加载时间变长，看起来时快时慢。

工作区已加入一个未签核修正：到点后保持 `sec_cnt=auto_period_sec` 和 `auto_due_q=1`，等新图真正发布或预取翻转完成后才重新计时。控制状态回归通过；该修正尚未重新综合、布线和上板，不能放入R3验收包。预读准入时序失败仍然独立记录。
