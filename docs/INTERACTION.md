# 交互与上板检查

扩展板按钮的当前连线在 `rtl/top/top_tf_hdmi_audio.v` 中，由 `exp_input_sync` 同步消抖。按下为低有效；不要把旧版本注释中的长按功能当作最终连线。

| 扩展板输入 | 当前事件 |
| --- | --- |
| KEY0 | 视频暂停/恢复 |
| KEY1 | 下一首歌曲 |
| KEY2 | 下一张图片 |
| KEY3 | 进入/退出视频 |
| KEY4 | 图片轮播开/关 |
| SW0…SW3 | 轮播周期，逻辑取反后映射为16档 |

轮播周期依次为2、3、5、8、10、15、20、30、45、60、90、120、180、240、300、600秒。配置在边界采用，避免改变正在加载或预取的会话。

板载按钮及键盘事件还经过 `button_ctrl`、`key_long` 和顶层模式判断。KEY3短按发出切图，长按判定后发出视频切换，长按不会同时误触发切图。视频模式屏蔽只推进音轨的单独快进，避免破坏音画时间线。键盘接口是否可用应以当前板级引脚复用和顶层参数为准。

## 一轮可记录的验收顺序

1. 冷启动，确认SD初始化后首图提交，记录从上电到显示的时间。
2. 每张图保持静止，观察横线、颜色、行序与左右方向；再连续切图并开启/关闭轮播。
3. 图片加载时切视频，视频退出后确认图片重新建立有效显示缓冲；切换中继续发出按键，确认无卡死。
4. 音乐模式跨PCM、QOA、IMA切歌，暂停/恢复；观察淡出、等待和渐入，记录爆音或长静音。
5. 播放422秒整段视频，记录1分钟、3分钟、结尾的音画关系，并跨至少两次循环；在循环接缝前后暂停/恢复。
6. 退出视频，恢复切图及音乐，复位后再重复一轮。

板测记录应包含bit SHA256、卡上文件SHA256、卡型号、使用接口、显示器型号和异常发生时间。SD卡在途请求不能被撤回；取消会话需要等待当前扇区完成。忙时按键不应以每次都显示中间帧作为通过条件，应检查最终目标、帧完整性和恢复能力。
