# 算法探索与生产选择

日期：2026-10-26整理，历史实验主要于2026-10-25完成。本文件保留决策依据，不把实验分支混称为当前RTL能力。

| 方向 | 作用位置 | 结果与选择 |
| --- | --- | --- |
| AMBTC启发的均值/绝对偏差代表色 | 离线编码 | 与原有双色细化组合后全片收益很小，未为其单独增加解码格式 |
| S2TC启发的多初值候选与颜色细化 | 离线编码 | 生产编码器保留有限候选迭代和颜色误差比较，不引入S2TC解码器 |
| 强边缘、误差梯度、跨块联合与时间权重 | 实验编码器 | 强权重损害全局误差，受限权重收益很小，未替换最终生产方案 |
| QUAD4 | Codec9新增token | 四个4×4象限各有代表色，以9字节表示一个8×8块，补足单色/双色与RAW之间的档位 |
| 率失真下凸包及增量收益/字节 | 离线编码 | 在给定帧预算下选择各块模式；提高预算无需改RTL |
| 相邻实色块RLE | Codec10新增token | 重建像素与Codec9一致，节省平坦区域字节，带宽可用于增加细节 |
| QOI/QOA/IMA | 图片/音频独立通路 | 已合入媒体读取，不是视频的替代解码器；保留各格式回压、异常与切换处理 |

历史Codec9 55000预算全片软件验证为6330帧，PSNR约30.969dB；后来Q125全片软件验证约34.212dB、MAE约2.452。不同硬件版本、码率和取样集之间不能直接归因于单一算法。最终Q125文件是Codec9像素语义经Codec10无损重封装，实际硬件支持以当前源和验证报告为准。

v19这次只合并读图与CMD17优化，不改变视频token格式。新增的视频画质/帧率探索另存本地video_limits_v19实验目录，尚未自动替换生产视频。固定分辨率下继续增加预算确实可提高重建质量，能否持续播放则必须同时测真实帧率取样、字节负载、SD仲裁、解码和音画授权等待。
