# 从v183到720P30候选的改动

基线是已上板确认的v183播放列表版本。本轮候选仍需完成最终峰值测试并上板验收；是否通过以交付清单和证据为准，不以文件夹名字判断。

## 外部行为

- 输入视频增加格式14/H6D1，目标为真实1280×720、30fps；显示接口保持720P60。
- 视频空间编码参数不降低，在原Codec12 token上增加可逆预测与Huffman编码。已有Codec12画质中的块感不会因此消失，但不新增量化损失。
- 全片伴音改用48kHz单声道IMA-XQ，属于有损音频。实验顶层关闭QOA音频硬件以容纳视频优化；PCM与IMA保留。图片QOI不受这项配置影响。
- 开播增加两帧预缓冲。暂停、手动上一部/下一部、结尾轮播及退出回音乐的操作方式保留，均需实际验收。

## 模块改动

| 源码 | 作用与改动 |
|---|---|
| `rtl/context_huffman_decoder.v`、`residual_tree.mem` | 同步ROM逐位树遍历，恢复六上下文Huffman符号；冻结码表必须与媒体编码器一致。 |
| `rtl/codec12_lossless_restore.v` | 将颜色差分与块内索引行预测逆变换回原Codec12 token，帧间独立重置。 |
| `rtl/codec_byte_queue.v` | 以小字节队列隔开熵解码与块解码的反压，保存顺序与帧边界。 |
| `rtl/video_player.v` | 接入H6D1，SD响应整组寄存、扩展字节FIFO、完成帧队列、两帧启动预缓冲、实际扫描区释放保护和独立解码/显示EOF计数。 |
| `rtl/video_byte_ram.v` | 增加显式深度及混合尾缓存：32KiB缓存用7块BRAM32K及4块BRAM9K；默认参数行为附等价验证。 |
| `user_source/hdl_source/SD/sd_card_sec_read_write.v` | 64扇区缓存、寄存器化地址命中检查、无符号下溢保护；物理CMD18读入时逐个交付已完整接收的逻辑扇区，减少解码等待。 |
| `user_source/hdl_source/SD/sd_card_top.v` | 传递缓存RAM类型与批量扇区数参数。 |
| `rtl/fat32_sector_mapper.v` | 寄存器化请求几何检查、游标恢复比较和链项验证；扩大批量读取的卷尾保护，并把音频FAT页缓存与视频/图片页缓存分离。仍逐逻辑扇区按FAT链映射，不要求整片连续分配。 |
| `user_source/hdl_source/SD/frame_fifo_read.v`、`frame_read_write.v` | 发布实际锁存的显示缓冲区编号与事件，原SDRAM地址和数据控制保持一致；wrapper透传反馈。 |
| `rtl/av_sample_sync.v` | 高帧率启动许可移到相邻60Hz边界之间，避免轻微时钟偏差导致过早换帧。每张实际展示新帧授予1600样本额度。 |
| `user_source/hdl_source/i2s_transmitter.v` | 仅在视频采样额度短暂耗尽时，最多保持两个完整采样对；不确认消费、跳过或重复读取源样本，长等待仍显露为缓冲。 |
| `media_player.v`、`media_player_shim.v`、`compressed_audio_reader.v` | 增加QOA可选开关，默认模块行为仍支持QOA；本候选顶层明确关闭，遇到QOA标记为不支持，避免误解码。 |
| `user_source/hdl_source/SD/bmp_read.v` | 图片头部长度与QOI字节边界比较分级寄存，缩短时序路径；QOI索引选择分布式LUT RAM，释放一块BRAM32K；图片缩放策略不随本轮视频帧率改变。 |
| `rtl/osd_player_ui.v` | 固定透明度常数使用等价移位加法，最终颜色与DE/VS一起寄存，缩短OSD到频谱的组合路径。 |
| `osd_brand_rom.v`、`anlogic_logo.mem` | 将1692项ROM补齐至2048项，补充值与原越界返回项一致，移除地址夹取逻辑；所有地址逐拍比较。 |
| `top_tf_hdmi_audio.v` | 设置缓存/音频配置，连接实际读帧编号CDC、音频额度及缓冲区释放反馈，匹配新增管线。 |
| `sd_arbiter.v` | 增加默认关闭的预读感知音频准入：仅对新的音频请求生效，储备充足且物理视频预读未结束时有界延后；低储备/1400000周期超时恢复资格，已接受事务保持。 |

最终候选还在`video_player.v`的V_REQ等待可写银行阶段允许压缩字节预读，但仅在已有显示/就绪帧时开启，保留首帧头部长度稳定期。顶层在SD时钟域寄存音频准入条件，来自同域PCM写侧水位与物理SD状态。该条件和测试平台的等价条件均有边界验证；不增加视频量化。

`residual_symbols.mem`、`residual_metadata.mem`保留码表生成与验证资料，当前树形硬件主要使用`residual_tree.mem`。约束、PLL、SPI时钟和CMD12清理长度未放宽。源码中历史设计注释可能描述早期配置；本候选实际参数以顶层实例、综合记录和本说明为准。

## 验证与限制

新增路径以精确源码哈希绑定测试结果。验证分为全片软件回解、完整720P像素与PCM、8136帧控制链、实际读帧锁存反馈、SPI引脚协议、FAT碎片边界、音频I2S和独立布线STA。已修改模块不直接借用旧版本的测试结论。

TD同进程重载SDC可能让报告时钟退化，必须在独立进程重新读取原约束并核对9个时钟。本轮未用假路径或降频掩盖内部违例。既有外部IO约束缺失与CDC物理可靠性边界单独列在coverage报告中。

片上BRAM32K已占16/16，后续功能不能假设仍有大块RAM可用。真实SD卡的额外延迟、碎片布局和采集端丢帧均需要上板验证；短时间测试的30fps不代表整片已经验收。正式发布稳定版前保留v183及其配套卡文件用于回退。
