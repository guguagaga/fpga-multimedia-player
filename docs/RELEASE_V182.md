# v182 稳定基线

2026-10-29，用户在更新SD配套影片后反馈“一切正常”。记录为用户报告的实物正常运行，不推断其已完成指定小时数、所有按键组合或全部温度/电压条件的验收。

## 改动

相较v114，纳入Codec12块表示、图片文件身份/显示适配和退出视频恢复原歌曲等后续修复。准确最终源码以manifest为准。
相较直接基线v180，本次RTL只修改sd_card_cmd、sd_card_top、spi_master：数据载荷字节由36核心周期缩短为32周期，核心约90.909MHz、SPI约22.727MHz和16扇区突发均保持。

原卡Codec10片头在受控模型中出现约12fps和最长16.667ms音频预算等待。v182配合新Codec12 Q125片头通过连续性检查。改进同时来自读取效率和媒体数据量下降，不能全部归因于SPI。

全片保持720P15，6330帧、422秒、738020352字节，比原984333824字节减少约25%。音轨仍为48kHz单声道PCM。三张留出样本PSNR有改善，但个别块边指标变差，不能宣称所有画面均改善或消除块感。

## 配套与回退

活动视频仍使用M1_C10.VID名称，文件头标识Codec12。旧片备份PRE182.BAK不是第二个活动视频。bit、影片、音轨哈希在release_status.json。
下载附件中的bit保留原INTERNAL_TIMING_PASS_BOARD_TEST文件名，确保与已测试二进制完全相同；新增加的板测反馈通过版本记录说明。

## 验证与剩余边界

独立进程读取最终布线库和原SDC：setup 0.000ns、hold +0.023ns。禁止引用同一构建进程中偏乐观的旧报告。18帧/57600采样联合测试通过，素材为3帧循环6次；不是全片RTL仿真。全片另有91152000块规范化相等与文件结构检查。图片/音乐相关回归按源码哈希复用，不能说成全部重跑。

今后修改在新候选中进行，v182作为可回退基线保留。上板新增检查按STABILITY_ROADMAP执行。
