# 2026-10-28 画质及音频恢复工作记录

## 本次起点

用户实测v113能显示图片和视频，但视频有块感、音频拖沓，屏幕进度三分多钟时音频单独从头重播。只读核对F卡：活动视频是Codec10、1280×720、15fps、6330帧/422秒的Q165全片，配套是48kHz/16bit/单声道PCM、422.069125秒；两个文件哈希匹配既有产物且FAT链有效、连续。不是短音轨或误用旧800×600文件。

## 画质实验结论

统一采用5个时间点（18、67、154、276、401秒），每处3帧，共15帧。所有图是软件重建的局部2倍最近邻放大图，不是实板屏摄。PSNR相对于同尺寸原片RGB565参考；块边指标是压缩误差在4/8像素网格两侧的梯度RMSE，属于客观代理指标，不能直接写成“观感提高多少百分比”。只检验局部样本，不代表全片平均或运动稳定性。

|方案|Q165样本PSNR|8像素块边梯度RMSE|部署状态|
|---|---:|---:|---|
|现有Q165|33.119dB|7.6031|现有格式|
|联合颜色拟合，权重1|32.955dB|7.1905|Codec10兼容候选，全片生成和播放验证另见状态|
|渐变块实验|33.413dB|7.2831|实验Codec11，不能给现有比特流播放|

1. 增加到Q185：全片已编码并完成91,152,000块C9/C10规范化等价检查；比特流无须改格式。但重场景SD并发仿真出现超过66.67ms的显示间隔，不能宣称持续15fps。尚未据此替换活动文件。
2. 单块评分加入局部梯度/边缘权重：15帧测得收益很小，一些指标变差，没有采用。
3. 相邻块联合颜色拟合：保持每块模式、索引、方向和C9帧字节数，优化代表色，使像素误差与块边梯度误差之和下降。权重1使8像素块边代理指标降低5.43%，PSNR下降0.164dB。较大权重虽进一步降低块边指标，但损失更多细节，因此未选。Codec10重复实色块的重打包大小可能改变，须看全片实际值，不能因C9大小相同就声称C10码率绝对不变。
4. 渐变块：新增0x86模式，9字节记录四个角点，在8×8内双线性插值。与平色QUAD4同样token长度，适合缓慢变化的背景/光影，复杂纹理仍选PAL2或RAW。5场景平均PSNR改善约0.294dB，4像素网格误差下降约5.9%。只是实验样本，未证明主观上大幅改善。

## 渐变块RTL可行性

research/gradient_research/gradient_block_experimental.v 是隔离的像素生成原型。用行/列前向差分、加法和移位实现与软件完全相同的双线性公式，不在源码中使用乘法器。4096组极值/随机角点、262144像素和随机暂停逐像素通过。

尚缺：生产token解析与头部格式识别、栅格通路整合、混合格式/复位/按键/长播放、真实SD吞吐、综合资源和全工程时序。不能据此宣称整机零DSP增加或时序可过，不能将实验Codec11文件放上当前卡。下一步若继续此架构，应先完成这些验证再讨论替换生产格式。

## 音频修改边界

v114只处理原LBA短读恢复、等待仲裁误计超时及音频独立重选策略，并新增故障显示。它没有证实或解决所有可能的实板触发源；高码率供数不足、物理SD延迟、时序违例仍是限制。v114最终setup WNS -1.980ns、hold +0.027ns，仍为TEST_ONLY。已记录全部失败/未完成状态，不以“静音不重播”充当完整修复。
